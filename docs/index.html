Wie viele fahren zu schnell?

SpeedTrigger zählt den Verkehr mit einer handelsüblichen Tapo-Kamera, misst jede Durchfahrt und zeigt, welcher Anteil über dem Limit liegt. Ohne Fotos von Fahrzeugen.

30

So wird gemessen

Das Prinzip ist eine Lichtschranke im Kamerabild: Zwei Linien mit bekannter Distanz, dazwischen wird die Zeit gestoppt.

  1. Linien setzen

    Im Tapo-Bild zwei Linien quer zur Fahrbahn anklicken und den realen Abstand vor Ort messen, idealerweise 15 bis 20 Meter.

  2. Fahrzeuge erkennen

    Bewegte Objekte werden vom Hintergrund getrennt und über mehrere Bilder verfolgt. Kleine Objekte wie Fussgänger oder Laub fallen heraus.

  3. Zeit stoppen

    Der Moment der Überquerung wird zwischen zwei Bildern interpoliert. Das gleicht die tiefe Bildrate der Kamera aus.

  4. Auswerten

    Jede Messung landet mit Zeit, Geschwindigkeit und Richtung in einer CSV-Datei. Ein Befehl erzeugt daraus den Bericht.

Was der Bericht zeigt

Ausschnitt aus dem Beispielbericht, erzeugt mit simulierten Daten einer Woche bei Tempo 30.

1789Fahrzeuge in 7 Tagen
16,5 %zu schnell, über 33 km/h
33,2V85 in km/h

V85 ist die Geschwindigkeit, die 85 Prozent der Fahrzeuge nicht überschreiten. Mit dieser Kennzahl arbeiten Verkehrsplaner. Dazu kommen die Verteilung nach Geschwindigkeit, der Tagesverlauf und die Werte je Fahrtrichtung.

Ganzen Beispielbericht öffnen

Zwei Betriebsarten

ZählmodusErfasst jede Durchfahrt mit Geschwindigkeit und Richtung. Es werden keine Bilder gespeichert.
TestlaufLöst zusätzlich eine Canon EOS per USB aus, sobald ein Fahrzeug die Schwelle überschreitet. Gedacht für eigene Kontrollfahrten, um die Messung zu prüfen.

Was du brauchst

  • Tapo-Kamera mit RTSP, zum Beispiel C200 oder C310, und ein eingerichtetes Kamerakonto
  • Windows-PC im selben Netz mit Python 3.11 oder neuer
  • Für den Testlauf: Canon EOS mit EDSDK-Unterstützung, etwa EOS R oder EOS 500D, und das kostenlose Canon EDSDK

Loslegen

git clone https://github.com/christophejenzer-collab/speedtrigger
cd speedtrigger
pip install -r requirements.txt

$env:TAPO_USER="..."; $env:TAPO_PASS="..."
python kalibrieren.py      # Linie A und B setzen
python speedtrigger.py     # Zählung starten
python auswertung.py       # Bericht erzeugen

Die vollständige Anleitung steht im README.

Grenzen

  • Kein geeichtes Messgerät. Die Werte sind Richtwerte und taugen nicht für Bussen oder Anzeigen.
  • Vor dem Einsatz mit Kontrollfahrten prüfen, die Geschwindigkeit dabei per GPS-App ablesen.
  • Nachts können Scheinwerfer und die Infrarot-Umschaltung der Kamera Fehlmessungen auslösen.

Datenschutz

Im Zählmodus speichert SpeedTrigger nur Zeit, Geschwindigkeit und Richtung. Kontrollschilder und Personen werden weder erkannt noch abgelegt.

Wer Fahrzeuge oder Personen im öffentlichen Raum fotografiert, bearbeitet Personendaten und ist selbst für die Rechtmässigkeit verantwortlich.
